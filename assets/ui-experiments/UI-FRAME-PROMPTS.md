## Assembly Notes for Claude (code integration)

When assets are ready, the integration approach:
1. Header bar → `background-image` on `.window-header` / `header`
2. Tab buttons → `background-image` on `.ace-tab` with `:hover` and `.active` variants
3. Side rails → `border-image` or pseudo-elements on panel sides, `background-repeat: repeat-y`
4. Bottom bezel → pseudo-element or dedicated div at panel bottom
5. Corners → absolutely positioned pseudo-elements at each corner
6. Content bg → `background-image` with `background-repeat: repeat` on content areas
7. Divider bar → `background-image` on separator divs between content sections
8. All pieces use `image-rendering: high-quality` and proper `background-size`
9. Theme switching: CSS custom properties or class swap on root panel element
   - `.ace-theme-dragonforge` / `.ace-theme-steamcraft` / `.ace-theme-tactical`
   - Each theme class changes the `--ace-frame-*` custom properties pointing to different asset paths
